# Historical framework plans

`plans/` preserves earlier framework plans with their original versions, paths,
commands and SHA values. They are historical evidence, not instructions for the
current tree. Moving a record does not establish acceptance for a new revision.

Earlier evaluation reports and source reviews now live under
[evals](../../../evals/README.md). Their original locations included `docs/evals`,
`docs/reviews` and `docs/architecture`, then `docs/archive`.
