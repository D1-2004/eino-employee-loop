# 国际化

[English](i18n.md)

本模块的非测试 Go 代码不含自然语言字符串。每条提示词、修复指令、上下文标签、工具与事件说明以及用户可见的文字，都来自 `i18n` 包解析的语言包。机器码（拒绝码、错误码、JSON 字段名）留在代码中。不作为输出的识别数据（例如钉钉网关的负面表情名单）是使用它的包的配置（`gateway/dws/reactions/`：`default.json` 放与语言无关的标识，每个语言一个 `<locale>.json`），不是语言包。

<a id="packs"></a>
## 语言包

语言包是扁平的 JSON 对象，存放在 `<dir>/locales/<locale>/<domain>.json`，嵌入拥有它的包的二进制中。值为字符串或字符串列表。同一语言的所有领域合并为一个键空间，因此键以领域名为前缀。

`i18n.Default()` 只包含 Loop 的语言包，由 `i18n` 包内嵌。其他需要输出文字的包内嵌自己的语言包，并提供 `LoadMessages(b)`（合并进一个 bundle）和 `Messages()`（`i18n.Default()` 的副本加上自己的语言包，用 `i18n.Extend` 构建）。因此一个服务的二进制只带它链接的包的文字。

| 语言包 | 位置 | 内容 |
| --- | --- | --- |
| `contract` | `i18n/locales`（默认 bundle） | 类别、模式、通道、会话与证据标签；标准目录的事件说明（`event.*`）；工具说明（`tool.*`） |
| `kernel` | `i18n/locales`（默认 bundle） | 修复与终止指令、上下文块标签、事件行格式 |
| `scene` | `i18n/locales`（默认 bundle） | 会话角色（`scene.session.<kind>`） |
| `toolhost` | `i18n/locales`（默认 bundle） | 标准工具保存的文字（记忆记录、问题选项） |
| `employeeloop` | `i18n/locales`（默认 bundle） | 默认人设、历史行格式 |
| `memstore` | `store/memstore/locales` | 记忆摘要文字 |
| `executors` | `taskmgr/executors/locales` | echo 执行器的输出（`taskmgr.echo.*`） |
| `stdin` | `gateway/stdin/locales` | stdin 网关的输出行（`gateway.stdin.*`） |
| `cmd` | `internal/cli/locales` | 命令参数说明与控制台输出 |
| `catalogdoc` | `internal/catalogdoc/locales` | 生成的 [catalog.zh-CN.md](catalog.zh-CN.md) 的标题与标签 |
| `runtime` | `prototype/core/locales` | 原型运行时（`core.Messages()`） |

随附的语言为 `en` 和 `zh-CN`。测试要求每个包的各语言拥有**完全相同的键集合**（`Bundle.Parity`），默认 bundle 不依赖回退就定义了契约目录需要的每个键（`i18n.ContractKeys`），并且不内嵌 Loop 领域以外的语言包。

<a id="resolution"></a>
## 解析

`Bundle.Resolve(tag)` 选择最合适的已加载语言：

1. 标签的规范形式（`zh_hans` -> `zh-Hans`，`EN-us` -> `en-US`）；
2. 精确匹配的语言包；
3. 文字别名：`zh-Hans` -> `zh-CN`，`zh-Hant` -> `zh-TW`；
4. 基础语言（`en-US` -> `en`）；
5. 同一语言的其他地区，按排序取第一个；
6. 回退语言 `en`。

`Bundle.Text(locale, key)` 先在解析出的语言中查找键，再在回退语言中查找，否则返回键本身，使缺口可见。

<a id="placeholders-and-lists"></a>
## 占位符与列表

- 文本占位符使用 `{name}`：`b.Text("en", "cmd.stopped", "service", "task-manager")`。
- `Bundle.List` 返回字符串列表（例如原型的示例脚本）。

<a id="overrides"></a>
## 覆盖

`i18n.Default()` 是共享的、只读的 Loop 语言包（各包的 `Messages()` 是加上了自己语言包的共享 bundle）。不改代码即可改变措辞：

```go
b := i18n.Default().Clone()
_ = b.Merge("en", map[string]any{"employeeloop.persona.default": "You are the front desk."})
raw, _ := os.ReadFile("packs/fr/contract.json")
_ = b.Load("fr", raw) // 新语言
```

把该 bundle 传给 `employeeloop.Config.Messages`、`scene.KernelRunner.Messages`、`kernel.Options.Messages`、`toolhost.WithMessages`、`memstore.WithMessages`、`stdin.Config.Messages` 或 `executors.EchoExecutor.Bundle`。已经带 `Description` 的 `ToolSpec` 会保留它：Host 自带的文本优先于 `description_key`。

<a id="choosing-the-locale-of-a-wake"></a>
## 选择唤醒的语言

- 命令：`-locale`，否则 `EMPLOYEE_LOCALE`，否则 `en`。
- `KernelRunner.Locale` / `employeeloop.Config.Locale` 是默认值；窗口最后一个事件设置了语言时以它为准。
- 投递带有窗口最后一个事件的语言。

<a id="adding-a-locale"></a>
## 新增语言

1. 对上表中的每个语言包位置，把 `locales/en/` 复制到 `locales/<locale>/` 并翻译每个值；键和占位符保持不变。
2. 运行 `go test ./...`；键集合测试和契约键测试会列出缺失项。
3. 生成该语言的目录文档：`go run ./cmd/catalog-doc -locale <locale> -o docs/catalog.<locale>.md`，并把该语言加入 `internal/catalogdoc` 中的 `shipped`，让测试持续检查它。

<a id="adding-keys"></a>
## 新增键

在同一次改动中把每个键加入所有随附语言，放在使用它的包的语言包（`<dir>/locales/<locale>/<domain>.json`）中，而不是别的包的语言包；默认 bundle 只收 Loop 的键。自定义事件类型需要 `summary_key`；自定义会话种类需要 `session.<kind>` 和 `scene.session.<kind>`；自定义工具需要 `description_key`（或 `description`）。修改目录或 `contract`/`catalogdoc` 的键之后，重新生成 `docs/catalog.md` 和 `docs/catalog.zh-CN.md`。
